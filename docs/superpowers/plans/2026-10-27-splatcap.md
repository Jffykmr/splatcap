# Splatcap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App iOS che cattura sessioni ARKit + LiDAR di qualità massima e le esporta in un formato che Spirula Studio carica dritto, preceduta da un convertitore Python che isola la causa del "storto" sulla capture Splatking esistente.

**Architecture:** Tre parti. (1) `tools/`: convertitore Python da PC, test locali con pytest. (2) `SplatcapCore`: Swift Package senza dipendenze da UIKit/ARKit (selezione fotogrammi, griglia di qualità, export), testato su runner macOS in CI. (3) `App/`: app iOS sottile (ARKit, vista live, termocamera, condivisione file) generata da XcodeGen, compilata senza firma in CI e installata con Sideloadly/AltStore.

**Tech Stack:** Python 3 + numpy + piexif + pytest; Swift 5.9+, SwiftPM, XcodeGen, ARKit, Metal/SceneKit (a scelta), GitHub Actions `macos-latest`.

**Spec:** `D:\dev\splatcap\docs\superpowers\specs\2026-10-27-splatcap-design.md`

## Global Constraints

- Sviluppo su Windows, nessun Mac. Swift si compila e testa solo in CI (GitHub Actions macOS), mai in locale.
- Nessun entitlement a pagamento, firma assente in CI; install con Apple ID gratuito (certificato 7 giorni, max 3 app).
- Repo GitHub pubblico, solo codice: nessuna cattura, nessun dato. `.superpowers/` e `captures/` in `.gitignore`. Creare/pushare il repo pubblico richiede conferma esplicita di Angelo.
- Un solo dispositivo di prova: l'iPhone 17 Pro di Angelo. Le scelte che dipendono dall'hardware (formato video, risoluzione foto) si fanno a runtime interrogando ARKit.
- Pose e intrinseci esportati sono quelli ARKit invariati. Pixel delle foto non ruotati né ricampionati; EXIF neutralizzato.
- Formato principale Nerfstudio `transforms.json` (`camera_model: "PINHOLE"`), extra COLMAP testo. Cartelle `images/`, `depths/`, file `seed.ply` con `x y z red green blue`.
- Termocamera: rosso = basso, giallo = medio, blu = buono (mai verde). Zone mai viste senza colore.
- Nessun training, nessun cloud, nessun account nell'app.
- Nessuna correzione automatica di grammatica nei testi italiani dell'app: la verifica è di Angelo.

## Review Focus

- **Tracking perso a metà cattura** (`limited`/`notAvailable`): i fotogrammi in quello stato non vengono salvati con pose false. Test in Task 5.
- **Nessun punto LiDAR utile** (sole forte, superfici lontane): la sessione si esporta lo stesso, senza `seed.ply`. Test in Task 2 e Task 6.
- **App chiusa o telefono pieno a metà cattura:** i fotogrammi già scritti restano esportabili e `transforms.json` si riscrive a intervalli. Test in Task 6.
- **Interruzione ARKit** (chiamata, app in background): il segmento successivo è marcato e non fonde pose incoerenti. Test in Task 7.
- **Scena grande o sessione lunga:** la griglia della termocamera ha memoria limitata. Test in Task 4.
